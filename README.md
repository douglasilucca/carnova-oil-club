# Carnova Oil Club V4 — Vehicles

## New feature
- Multiple vehicles per customer
- Add, edit and remove vehicles
- Year, make, model, trim, VIN, plate, color and mileage
- Registered vehicle selection during oil-change redemption
- Mileage automatically updates after a service
- Vehicle linked to permanent service history
- Customer public card displays registered vehicles
- Existing Stripe, members, service history and PostgreSQL data preserved

## Deployment
Upload all files and folders to the root of the existing GitHub repository.
Commit the changes and allow Render to deploy automatically.

Do not delete the PostgreSQL database or environment variables.
